Dr. Ali Abbas Pharmacy Website

An Arabic-first, right-to-left catalog site for a real pharmacy in Ain Shams, Cairo, built with React 19 and TypeScript. Visitors search 23,858 medicines by their Arabic or English name, open a page for any of them, and send a prefilled WhatsApp inquiry from a basket kept in the browser. It is a catalog and inquiry tool on purpose: no checkout, and no claim about live stock or selling prices.

  • A build step generates every medicine page, the alphabetical index and the sitemap: 23,908 URLs
  • Deep links return real HTML with their own title, canonical, Open Graph tags and JSON-LD breadcrumbs
  • Search and ranking run in the browser on a committed CC0 snapshot, with a labeled 45-medicine fallback
  • 19 Vitest unit tests guard the Arabic search, the WhatsApp message, image matching and the generator
